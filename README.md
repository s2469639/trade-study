# 🚢 무역공부노트 (trade_study)

해외영업 취업 준비를 위한 **나 혼자 쓰는** 공부 웹페이지. Flask + 순수 HTML/CSS/JS, 로그인·DB 없음.

## 실행

```bash
cd trade_study
pip install -r requirements.txt
python app.py        # → http://127.0.0.1:5000
```

## 이렇게 생겼어요 (월드맵 + 졸라맨 모험)

홈은 **월드맵**이에요. 섬(산업)과 마을(나머지 메뉴)을 누르면 노란 모자 **삐약이**가 배를 타고 달려가요.

| 장소 | 내용 |
|---|---|
| 산업 섬 (반도체 / 2차전지 / 자동차) | 개요·구조·제품·기업·시장·이슈, 섬 퀴즈, **스탬프 수첩(별 5개)** |
| 기업 항구 | 사업부문·해외사업·경쟁사·채용공고 분석·메모, 기업 직접 추가 |
| 무역 항구 이야기 | 삐약이와 파도 선배의 수출 스토리 4챕터 (선택지를 고르며 실무 익히기) |
| 무역 학원 | 프로세스·서류·결제·운송·통관·용어집·사례 |
| 신문사 | 뉴스를 요약 / 배경지식 / 왜 중요한가로 정리 |
| 글쓰기 도서관 | 사설 정리, 내 글, 체크리스트, 표현 노트 |
| 면접 회관 | 질문 28개, 랜덤 뽑기, 타이머, 설명해보기 |
| 나의 일지 | 전체 타임라인, 모아보기, 모르는 것, 백업 |

### 게임 요소
- **경험치(XP)와 레벨**: 공부 기록, 뉴스 정리, 면접 답변, 스탬프, 스토리 클리어로 올라요 (`game.py`).
- **모자 장식**: 레벨이 오를 때마다 삐약이의 모자에 장식이 하나씩 생겨요 (별핀, 리본, 꽃, 프로펠러, 닻 배지, 금띠, 깃발, 선글라스, 왕관). 목록은 `data/hats.json`.
- **섬 스탬프**: 상륙 / 탐험 노트 / 뉴스 수집 / 면접 도전 / 섬 퀴즈 통과.
- **오늘의 퀘스트**: 용어 3개, 뉴스 1개, 공부 기록, 면접 답변.

## 폴더 구조

```
trade_study/
├─ app.py          # 화면 주소(라우트)와 저장 API
├─ storage.py      # 데이터 읽기/쓰기 (나중에 DB로 바꿀 때 이 파일만 수정)
├─ templates/      # 화면(HTML). base.html = 공통 틀, 메뉴당 파일 1개
├─ static/
│  ├─ css/style.css   # 디자인 (색·폰트는 맨 위 :root)
│  ├─ js/app.js       # 공통 동작 (탭, 저장, 삭제, 필터)
│  └─ fonts/          # 내 폰트 넣는 곳 → fonts/README.md
└─ data/
   ├─ *.json          # 샘플 데이터 (직접 고치면 화면에 반영)
   └─ user/           # 내가 저장한 기록 (git 제외)
```

## 자주 하는 수정

- **샘플 데이터 고치기/늘리기**: `data/industries.json`, `companies.json`, `trade.json`, `interview.json`을 열어 같은 모양으로 추가.
- **색 바꾸기**: `static/css/style.css` 맨 위 `:root`의 `--yellow`, `--sky`, `--blue`.
- **폰트 바꾸기**: `static/fonts/README.md` 참고.
- **새 기록 종류 추가**: `storage.py`의 `COLLECTIONS`에 이름 추가 → HTML 폼에 `data-collection="이름"`.

## 알아둘 점

- 샘플 데이터는 **공부 출발점용**이고 `샘플` 표시가 붙어 있어요. 면접에서 쓸 사실은 반드시 직접 확인해서 고쳐 쓰기.
- 내 기록은 `data/user/*.json`에 저장돼요. 📒 기록 → 💾 백업 탭에서 파일로 받아둘 수 있어요.

- **스토리 늘리기**: `data/story.json` 에 챕터를 같은 모양으로 추가하면 돼요 (say 대사 / choice 선택지).
- **섬 퀴즈 고치기**: `data/quiz.json`.
- **아이콘 추가**: `templates/_icons.html` 에 symbol 을 추가하고 `{{ ico('이름') }}` 으로 불러요. (이모지는 쓰지 않아요)
- **환율 API (ExchangeRate-API)**: 프로젝트 폴더에 `.env` 파일을 만들고 `EXCHANGE_API_KEY=내키` 한 줄을 넣으면, 홈의 "오늘의 환율"과 무역 학원의 환율 계산기·환차손익 시뮬레이터가 켜져요. 키는 서버에서만 쓰고, 결과는 `data/cache/` 에 6시간 저장해서 무료 호출 횟수를 아껴요. (`rates.py`)
- **인코텀즈 슬라이더** (무역 학원): 11개 규칙을 골라 보며 수출자와 수입자가 맡는 10개 구간과 위험 이전 지점을 확인하고, 구간별 사고 시 누가 부담하는지 시험해 봐요. (`data/incoterms.json`)
- **용어 퀴즈** (무역 학원 > 용어집): 설명을 보고 용어를 맞혀요. 맞히면 외운 용어로, 틀리면 `모르는 것`에 복습 항목이 담겨요.
- **모의 면접** (면접 회관): 면접관 캐릭터가 질문하고 90초 안에 답하면, `data/interview.json` 의 `keywords` 로 핵심 키워드를 얼마나 담았는지 알려줘요. 답변은 자동 저장돼요.
- **공부 잔디 + 연속 일수** (홈, 나의 일지), **파도 선배의 한마디** (`data/tips.json`).
- **내 옷장** (`/closet`): 이름, 모자 색, 자리별 장식(모자 위, 모자띠, 핀, 얼굴, 목, 볼)을 골라 꾸며요. 고르는 즉시 미리보기가 바뀌고 `저장하기`로 저장돼요. 장식과 색은 레벨뿐 아니라 스토리 클리어, 스탬프, 연속 공부, 외운 용어 같은 조건으로도 열려요. 목록과 조건은 `data/hats.json`.
- **월드맵 확장**: 산업 섬 8개(반도체, 2차전지, 자동차, 조선, 화학, 화장품, 식품, 바이오·제약)가 3개 군도로 묶여 있고, 안 가본 섬은 안개가 껴 있어요. 배가 곡선 항로로 항해하며, 별 5개를 모으면 섬에 깃발이 꽂혀요.
  - **산업 섬 추가하는 법**: `data/industries.json` 에 산업 하나를 같은 모양으로 추가하고 `icon`, `region`, `map`(x, y, shape 0~2, color)을 적으면 지도에 자동으로 나타나요. 퀴즈는 `data/quiz.json`, 면접 질문은 `data/interview.json`, 기업은 `data/companies.json`, 군도 이름은 `data/map.json`.
  - 새 아이콘이 필요하면 `templates/_icons.html` 에 symbol 을 추가해요.
  - **섬 숨기기/되살리기**: `data/industries.json` 의 산업에 `"hidden": true` 를 적으면 지도와 목록에서 빠져요 (딸린 기업·면접 질문도 같이). 데이터는 그대로 남아 있어서 줄을 지우면 다시 나타나요. 지금 `철강`이 숨겨져 있어요.
  - **지도 그림**: 지도 전체가 평평한 바다색이에요. 섬에는 옆면(두께), 물에 닿는 거품, 그림자가 있어요. 장식은 `templates/_map.html` 에서 바꿔요.

## 배포하기 (Render, 과제 제출·친구 공유용 체험판)

`DEMO_MODE=1` 로 켜면 **방문자마다 기록이 따로 저장되고 서로 보이지 않아요.** (쿠키의 랜덤 id 로 폴더를 나눠요.) 내 컴퓨터의 `data/user/` 기록은 배포에 올라가지 않아요.

1. https://render.com 에 가입하고 GitHub 계정을 연결해요.
2. **New → Blueprint** 에서 `trade-study` 레포를 고르면 `render.yaml` 을 읽어서 설정이 채워져요. (직접 만들 때는 **Web Service** 로 만들고 Build: `pip install -r requirements.txt`, Start: `gunicorn app:app --workers 1 --threads 4`)
3. **Environment** 에 `DEMO_MODE=1` 이 들어 있는지 확인하고, 환율을 쓰려면 `EXCHANGE_API_KEY` 를 직접 입력해요. (키는 코드나 레포에 넣지 않아요)
4. 배포가 끝나면 나오는 주소를 공유해요.

알아둘 점
- 무료 요금제는 한동안 접속이 없으면 서버가 잠들어서 **첫 접속이 느릴 수 있어요.** 서버가 재시작되면 방문자 기록은 사라져요. (체험판이라 괜찮아요)
- 방문자 폴더는 3일이 지나거나 300개를 넘으면 자동으로 정리돼요. 기록 하나는 20KB, 한 종류당 200개까지만 저장돼요.
- 체험판에서는 백업 불러오기가 막혀 있어요.
- 요금제와 화면 이름은 바뀔 수 있으니 Render 안내를 같이 확인하세요.
